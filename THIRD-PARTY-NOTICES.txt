Third-party notices for the aggrega binary

This file lists every third-party dependency compiled into the aggrega binary:
the host (aggrega) and each embedded plugin, named <socket>/<name> (provider/helm, provider/compose, provider/helm-chart, provider/terraform, provider/cloudformation, provider/arm, linter/publishing, parser/hcl, parser/toml, parser/yaml, parser/json, parser/jsonc, governance/label-injector, governance/selector-tagger, governance/rego, governance/cel).
It is generated from the dependency set the binary is built from; do not edit it.

Each dependency below names its version, its license, the copyright lines found in
its package, any notice file it ships and what it is compiled into. The text of
each license follows once, under its SPDX identifier.
