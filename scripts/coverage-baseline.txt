# Per-package coverage floor manifest.
#
# Each line records the minimum acceptable per-package coverage as
# reported by `go test -cover`. The coverage-gate script reads
# this manifest, runs `go test -cover`, and fails the build if any
# listed package falls below its declared floor.
#
# The floor (90) is the target threshold, not the achieved number.
# A package landing at 92% is allowed to drop to 90% but not below.
# The manifest is extended as new packages cross the 90% line.
#
# Carve-outs below the 90% line carry inline rationale describing
# which functions are excluded and why per-function unit tests are
# categorically less valuable than the alternative coverage source
# (binary smoke tests, downstream package failure-mode coverage).
#
# Run the gate with:    scripts/coverage-gate.sh
# Also check cross-pkg: scripts/coverage-gate.sh --cross
#
# Format: <package-import-path> <floor>

# cmd/aggrega: 82% achieved + Phase 5 exclusion-list carve-outs.
# The package's residual gap below 90% is:
#   - main() and Execute() — CLI bootstrap (the binary's `os.Args` →
#     library-call translation). Behavior verified by binary-level
#     smoke tests, not per-function unit tests. Excluded from the
#     90% floor via Phase 5's exclusion-list mechanism.
#   - runBuild's subsystem error-propagation paths — each branch
#     wraps a downstream package's error (resolver, topology, ir,
#     analyzer, renderer). The downstream packages' own coverage
#     pins their failure modes; the wrapping is mechanical.

# cmd/mutation-baseline: 64% achieved + Phase 5 exclusion-list
# carve-outs. The package's residual gap below 90% is:
#   - main() — CLI bootstrap that translates flags and triggers the
#     run. Behavior verified by binary-level smoke test (the binary's
#     --smoke-only invocation is part of every full baseline run).
#   - findAggregaCliRoot, commitHash — filesystem + subprocess
#     primitives whose unit testability would require faking the
#     filesystem/exec layer. Cost exceeds value at the carve-out
#     site.
#   - goTestRunner.RunTests — `go test` subprocess invocation. The
#     fakeRunner-based RunMutations tests already cover the
#     classification logic; the wrapping over exec.Command is
#     mechanical.
#   - runSmoke, runSingleMutation — orchestration wrappers over the
#     tested RunMutations + FindMutations building blocks. Behavior
#     verified by --smoke-only invocation as part of every run.
github.com/cognitio/aggrega-cli/cmd/mutation-baseline       64

# cmd/mutation-baseline/smokeprobe: 50% achieved by deliberate design.
# The package carries one tested function (probe.go:TrueAlways) and one
# untested function (uncovered.go:UncoveredFunc) so the mutation-baseline
# binary's --smoke-only check has stable known-killed and known-survived
# targets. Adding a test for UncoveredFunc defeats the smoke check's
# purpose. The 50% floor locks in this intentional shape.
github.com/cognitio/aggrega-cli/cmd/mutation-baseline/smokeprobe  50
