Next steps

Run the AI quickstart. In a new PowerShell window, run:

    irm https://aggrega.ai/quickstart-ai.ps1 | iex

Add the Aggrega skill to the AI assistants on this machine. In a new terminal, run:

    aggrega skills install --global

Set up shell completion and connect your AI client to the Aggrega MCP server, as this page describes:

    https://aggrega.ai/docs/install/
